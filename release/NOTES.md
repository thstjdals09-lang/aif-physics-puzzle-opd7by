## 1. Release Build: 배포파일·버전 태그·릴리즈노트 생성

### 1.1 배포파일 생성
배포파일을 생성하는 과정은 다음과 같습니다:

1. **프로젝트 빌드**: 프로젝트를 빌드하여 최종 배포 파일을 생성합니다.
   ```bash
   npm run build
   ```

2. **배포파일 확인**: 생성된 배포파일이 `dist` 폴더에 위치하는지 확인합니다.

### 1.2 버전 태그 생성
버전 태그를 생성하여 배포 버전을 관리합니다.

1. **현재 버전 확인**: 현재 프로젝트의 버전을 확인합니다.
   ```bash
   npm version patch
   ```
   또는
   ```bash
   npm version minor
   ```
   또는
   ```bash
   npm version major
   ```

2. **버전 태그 확인**: 생성된 버전 태그가 Git 리포지토리에 추가되었는지 확인합니다.

### 1.3 릴리즈노트 생성
릴리즈노트를 생성하여 배포 내용을 문서화합니다.

1. **릴리즈노트 작성**: `CHANGELOG.md` 파일을 열고, 새로운 릴리즈 내용을 작성합니다.
   ```markdown
   ## [1.0.0] - 2023-04-01

   - Initial release
   - Added core mechanics
   - Implemented user interface
   - Integrated backend systems
   ```

2. **릴리즈노트 확인**: 작성된 릴리즈노트가 정확하고 충분한 내용을 포함하고 있는지 확인합니다.
